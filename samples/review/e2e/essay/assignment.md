# SE-230 Concurrency Concepts — Written Assignment 3

## Task
Write a report that discusses two models of concurrency: operating-system threads and coroutines scheduled by an
event loop.

## Requirements
1. The report must discuss how threads share work, including the effect of the CPython global interpreter lock.
2. The report must discuss how coroutines on an event loop interleave many waiting tasks in one thread.
3. The report must analyse which model suits a service with many idle connections, with reasons.
4. Every factual claim must be supported by a citation to a source.
5. End with a conclusion that summarises the findings and recommends one model.

## Constraints
- The report may not exceed 1500 words.

## Deliverables
- The report as a single document.

## Evaluation (30 marks)
| Criterion | Marks |
| Analysis of the two models | 15 |
| Use of sources | 10 |
| Structure and writing | 5 |
