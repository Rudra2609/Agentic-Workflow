Compiler Design — Assignment 1: Expression Evaluator

Write a program that reads arithmetic expressions from a file, one per line, and prints the value of each expression.

Requirements
R1. Support integers and floating point numbers, the operators + - * / and ^ (power), unary minus, and parentheses.
R2. Respect the usual precedence and associativity: ^ is right-associative and binds tighter than * and /, which bind tighter than + and -.
R3. Build an abstract syntax tree before evaluating; evaluating directly while parsing is not accepted.
R4. Report syntax errors with the line number and the column of the offending token, then continue with the next line.
R5. Division by zero must produce the message "error: division by zero" instead of crashing.
R6. Optionally (bonus 10 marks), support variables with assignments such as x = 3 + 4.

Constraint: write the lexer and parser by hand. Parser generators such as ANTLR, yacc or PLY are not allowed. Any of C, C++, Java or Python may be used.

Submit the source code, a file of at least 20 test expressions with expected outputs, and a one-page explanation of your grammar.

Marks: lexer 20, parser and AST 35, evaluation 20, error handling 15, documentation 10 (total 100), plus 10 bonus marks.
