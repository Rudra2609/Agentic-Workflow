Software Engineering Project — Phase 2
Library Management REST API

You are asked to implement the backend of a small library management system.

The system shall:
- allow librarians to add, update and delete books (title, author, ISBN, number of copies);
- allow members to search books by title or author;
- allow members to borrow a book if at least one copy is available, and return it later;
- prevent a member from borrowing more than 3 books at the same time;
- record a fine of Rs. 5 per day for every book returned after its due date (14 days after borrowing);
- expose all operations as JSON REST endpoints.

Non-functional expectations: every endpoint should respond within 300 ms for a database of 10,000 books. Passwords must be stored hashed, never in plain text.

Technology constraints: use Python with FastAPI or Flask, and SQLite or PostgreSQL as the database. The API must be documented with OpenAPI/Swagger.

What to submit:
1. The Git repository link containing the source code.
2. A Postman collection (or equivalent) that exercises every endpoint.
3. Unit tests with at least 70% line coverage.
4. A design document with an ER diagram.

Marking scheme:
API correctness — 30 marks
Borrowing rules and fines — 20 marks
Tests and coverage — 20 marks
Design document — 15 marks
Code quality — 15 marks
Total: 100 marks
