CS-342 Computer Networks — Lab Assignment 4
Multi-Client Chat Server

Objective
In this lab you will build a text chat system made of a server and a command-line client.

Functional requirements
1. The server must accept connections from at least 10 concurrent clients.
2. Each client must register a unique username before sending messages. Duplicate usernames shall be rejected with an error message.
3. Every message sent by a client must be broadcast to all other connected clients, prefixed with the sender's username.
4. The server must support private messages using the command /msg <user> <text>.
5. The server shall notify all clients when a user joins or leaves the chat.
6. A client should be able to list the users who are online with the /who command.

Constraints
- Implement everything in Python 3 using only the standard library (socket, threading or asyncio). Third-party networking frameworks are not allowed.
- The server must listen on port 5050 by default; the port may be changed with a command-line argument.

Deliverables
- Source code (server.py and client.py) submitted as a single zip file.
- A README explaining how to run the server and the client.
- A 2-page report (PDF) explaining the concurrency model you chose.
- A demo video of at most 3 minutes.

Evaluation (100 marks)
| Criterion | Marks |
| Correct broadcast to all clients | 25 |
| Username registration and duplicates | 15 |
| Private messages | 15 |
| Join/leave notifications | 10 |
| Code quality and comments | 15 |
| Report | 20 |

Submission deadline: end of week 9. Late submissions lose 10% per day.
