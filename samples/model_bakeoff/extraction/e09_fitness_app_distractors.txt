Mobile Application Development — Project Brief (version 2, updated for this semester)

Read carefully: this brief replaces last year's version. Last year's project required smartwatch integration and a
leaderboard; neither is required this year. The ideas listed under "Inspiration" at the end are optional and not graded.

Build a personal fitness tracker app. The app must let users log workouts (type, duration and calories) and must show a
weekly summary chart. If the daily step goal has not been reached by 8 pm, the app shall send a reminder notification.
Users must be able to export all their data as a CSV file. The app has to work fully offline and synchronise with the
server when a connection becomes available. Every button needs a screen-reader label so the app is usable with
accessibility tools.

Build it with Flutter or React Native. Paid third-party APIs are not allowed, and the installed app must be smaller than 50 MB.

Hand in: an installable build (APK or IPA), the link to your source repository, a user manual of at most 5 pages, and a
test report.

Marks: features 40, user experience and accessibility 20, offline sync 15, testing 15, documentation 10.

Inspiration (optional, ungraded): social sharing of workouts, a dark mode theme, voice coaching.
