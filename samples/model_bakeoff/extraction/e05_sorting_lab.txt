Algorithms Lab 3 — Empirical Analysis of Sorting

Implement insertion sort, merge sort, quick sort (with random pivot) and heap sort.

Requirements:
- Each algorithm must sort a list of integers in non-decreasing order and must not use the language's built-in sort functions.
- Measure the running time of each algorithm on inputs of size 1,000, 10,000 and 100,000 for three input types: random, already sorted and reverse sorted.
- Repeat every measurement 5 times and report the median.
- Plot running time versus input size for every algorithm on a log-log scale.
- Count the number of comparisons performed by each algorithm and report them alongside the times.

You may use C++ or Java. Python is not permitted for this lab because of timing noise.

Deliverables: source files, a CSV file with all measurements, and a lab write-up (max 4 pages) that compares the observed growth rates with the theoretical complexity.

Marks: implementations 40, experiment design and measurements 20, plots 15, write-up 25. Total 100.
