Write two functions on a list sorted in non-decreasing order, using binary search
(do not use the `bisect` module and do not scan the list linearly):

- `insert_position(xs: list[int], x: int) -> int` — the leftmost index where `x` could be inserted keeping the list sorted.
- `count_occurrences(xs: list[int], x: int) -> int` — how many times `x` appears.
